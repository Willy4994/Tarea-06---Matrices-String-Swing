# Sesión 08 - Programas Java

Este repositorio contiene los programas transcritos y codificados de la sesión 08, incluyendo:

- Datos tipo vector
- Datos tipo matriz
- Constructor de la clase
- Clase String
- Interfaces visuales con Swing
- Programas del documento `Practica2-Java-Tarea.pdf`

## Requisitos

- Java JDK instalado
- Git instalado
- Visual Studio Code, NetBeans o IntelliJ IDEA (opcional)

## Cómo compilar todos los programas

Desde la carpeta `src`, ejecutar:

```bash
javac *.java
```

## Cómo ejecutar un programa

Ejemplo:

```bash
java Problema01VectorAnalisis
```

Para programas con interfaz gráfica, ejecutar por ejemplo:

```bash
java Problema10LoginSwing
```

## Subir a GitHub

```bash
git init
git add .
git commit -m "Programas sesión 08 Java"
git branch -M main
git remote add origin https://github.com/TU_USUARIO/sesion08-java.git
git push -u origin main
```

Después, copiar el enlace del repositorio y enviarlo como entrega.
